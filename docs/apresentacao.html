A descoberta crítica

O campo SUMÁRIO entrega o veredito

O SUMÁRIO é redigido pela Secretaria do TCU após a decisão e contém literalmente o texto do julgamento. Usar esse campo como feature é entregar a resposta ao modelo antes da prova.

Por que F1-macro?

Com 91% de uma classe, a acurácia engana: prever sempre "Irregular" dá 0,91 de acurácia — mas F1-macro de apenas 0,32. O F1-macro revela se o modelo aprende de fato as classes raras.

Por que o baseline supera
deep learning?

  • Corpus pequeno + desbalanceamento extremo — apenas ~240 exemplos de Ressalva e ~93 de Regular. Insuficiente para fine-tuning robusto de 110M parâmetros.
  • Sinal predominantemente lexical — presença/ausência de termos específicos é mais discriminativa que representações semânticas densas neste corpus.
  • TF-IDF vê o documento inteiro — sem truncagem a 512 tokens. BERT perde informação em votos longos (mediana ~1.800 tokens).

O gargalo é dado

Conclusão

Resultado honesto,
não resultado inflado

  • Correção de vazamento é inegociável — F1 ~0.99 com SUMÁRIO era ilusão. O pipeline audita automaticamente antes de treinar.
  • Baseline clássico supera deep learning — TF-IDF 0.491 contra LegalBert 0.335. Corpus pequeno + desbalanceamento extremo favorece modelo linear.
  • Ponderação de classes é requisito — sem ela, F1 cai de 0.491 para 0.317 (classes raras colapsam a zero).
  • O gargalo é a escassez de dados nas classes raras — não a capacidade da arquitetura.
